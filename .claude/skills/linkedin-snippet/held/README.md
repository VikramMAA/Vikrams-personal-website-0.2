# Held drafts

Posts that cleared the linter but were not posted, kept so the good ones are
not lost while the shelf waits.

They live here rather than in the scratchpad because the scratchpad is
session-scoped and gets cleared. On 2026-11-27 a worker restart wiped it and
took a month of drafts with it; the only reason they came back is that the
Copy Desk artifact happened to still be carrying them in its seed data. That is
luck, not a backup.

The Copy Desk shows the best three of these as HELD tabs. The rest live only
here, so this directory is the real shelf and the desk is a view of it.

Each file is one post, already linted clean, named by the date of the article
it came from. Re-run the linter before posting anything out of here: the banned
phrase list is shared with the article linter and moves.

    python3 ../scripts/lint_snippet.py 2026-11-25-whatsapp-list.txt

Nothing here has been posted anywhere.
